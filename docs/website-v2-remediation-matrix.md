## 1. Classification Protocol

Every item from the v1 and v2 audits is reconciled below against approved engineering records, corporate filings with BSE Limited, and statutory compliance frameworks. Each finding is assigned one of the 7 official status classifications:

- **RESOLVED**: Code and content change implemented, verified via automated sensor / test suite, and confirmed in build.
- **IMPLEMENT**: Actionable code remediation implemented in current cycle.
- **PARTIALLY RESOLVED**: Technical defect eliminated; awaiting physical certificate scans or third-party filing assets.
- **BLOCKED — SOURCE REQUIRED**: Requires authentic scanned documentation, high-resolution original photography, or third-party reports not yet supplied.
- **BLOCKED — APPROVAL REQUIRED**: Requires formal sign-off from Board of Directors, Managing Director, or Company Secretary.
- **REJECTED — CONFLICTS WITH APPROVED GOVERNANCE**: Audit proposal conflicts with statutory facts, approved corporate structure, or engineering specifications.
- **NOT APPLICABLE**: Third-party hosting notices, promotional tags, or irrelevant infrastructure items excluded by governance.

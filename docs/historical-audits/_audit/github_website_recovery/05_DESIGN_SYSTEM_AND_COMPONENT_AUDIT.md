#### B. Typography System

Fonts are loaded via Google Fonts preconnect in [__root.tsx:L92-95](file:///C:/Users/abc/.gemini/antigravity-ide/scratch/pixel-perfect-painter-750/src/routes/__root.tsx#L92-L95):

- **Display Headings (\`--font-display\`)**: \`"Archivo", ui-sans-serif, sans-serif\` (weights 500, 600, 700, 800). Archivo provides architectural geometric impact, reminiscent of DIN / Eurostyle signage.
- **Body & Controls (\`--font-sans\`)**: \`"IBM Plex Sans", ui-sans-serif, sans-serif\` (weights 400, 500, 600). Highly readable, utilitarian technical prose.
- **Eyebrows & Technical Metadata (\`--font-mono\`)**: \`"IBM Plex Mono", ui-monospace, monospace\` (weight 500). Used for numerical badges (\`01\`, \`02\`), location tags, and uppercase status indicators.

#### C. Custom Layout Utilities & Geometry

- **Radius**: \`--radius: 0.125rem\` (2px). The UI strictly enforces crisp, sharp corners (almost square), reinforcing structural steel fabrication.
- **\`.eyebrow\` Utility**: Uppercase, monospace, 0.72rem text used for section pre-headers.
- **\`.blueprint\` Utility**: Applies \`--primary-deep\` background for the Shivlakha logistics portal and footer.
- **\`.hatch\` Utility**: Applies technical industrial background hatching to placeholder image figures.
- **Motion Safety**: Media query \`@media (prefers-reduced-motion: reduce)\` disables animations globally ([styles.css:L147-150](file:///C:/Users/abc/.gemini/antigravity-ide/scratch/pixel-perfect-painter-750/src/styles.css#L147-L150)).

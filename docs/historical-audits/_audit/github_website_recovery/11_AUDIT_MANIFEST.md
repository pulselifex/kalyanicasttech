### 2. Inspection Methods & Commands Executed

All inspection commands executed were non-destructive and read-only. No application files were modified or deleted.

#### Commands Executed During Audit:

1. \`git status\` — Verified initial working tree state (Clean).
2. \`git remote -v\` — Identified upstream repository URL.
3. \`git log -1 --stat\` — Checked latest commit metadata and commit message.
4. \`git branch -a\` & \`git tag\` — Verified branches and tags.
5. \`git count-objects -vH\` — Measured packfile and object count.
6. \`git log --oneline --reverse\` & \`git log --stat\` — Extracted complete history of all 28 commits.
7. \`git ls-files\` — Extracted list of all 125 tracked repository files.
8. \`git diff-tree\` & \`git diff\` — Traced evolution of \`pages.json\`, \`package.json\`, and styling.
9. \`git log --diff-filter=D --summary\` — Identified deleted files in history (\`public/favicon.ico\`).
10. \`curl -I <logo_cdn_url>\` — Verified remote logo availability on Cloudflare/Application Template CDN.
11. \`node scratch/audit_inspector.mjs\` — Analyzed all TypeScript/TSX imports and UI usage.
12. \`node scratch/generate_audit_package.mjs\` — Generated CSV registers, JSON summary, and contact sheets.
13. \`git status\` — Verified final working tree state (Only untracked \`_audit/\` exists; 0 tracked files modified).

#### Commands Intentionally Withheld & Why:

1. \`npm install\` / \`bun install\` — **Withheld**: Strictly prohibited by non-negotiable safety rules ("Do not install or upgrade project dependencies unless explicitly authorised").
2. \`npm test\` / \`vitest run\` — **Withheld**: Cannot be executed because \`node_modules\` is not installed in the workspace.
3. \`npm run build\` / \`vite build\` — **Withheld**: Requires uninstalled dependencies; would create build artifacts.
4. \`git push\` / \`git reset\` / \`git checkout\` — **Withheld**: Prohibited to prevent modifying published Git history or workspace state.
5. Live Form Submission Testing — **Withheld**: Prohibited to prevent dummy data generation or potential network side effects.

### 3. Limitations of the Audit

1. **Absence of Local Node Modules**:
   Because dependencies were not pre-installed in the cloned repository and installing them was forbidden by safety guidelines, dynamic runtime checks (such as launching a headless browser to render the local Vite dev server) could not be executed. All findings are based on static AST parsing, code tracing, and remote asset inspection.
2. **CDN-Hosted Logo**:
   The primary company logo binary was not stored in Git, but rather as an asset pointer JSON file referencing Application Template's CDN. While successfully preserved offline by this audit, this represents an operational dependency on external infrastructure.
3. **Absence of Raster Photography in Source**:
   The repository contains zero product or plant photography. All image locations are design placeholders.
